# CPAT-GUI 自動解析システム (NSDKIT/pspt)

本リポジトリは、電力系統解析ツール「CPAT-GUI」を用いた自動解析システムの実行環境およびスクリプト群です。
この README は、**研究を引き継ぐ後輩の方**に向けて、システムの概要から環境構築、実行手順までを分かりやすく解説したものです。

---

## 1. システムの概要

本システムは、電力中央研究所が開発した電力系統解析ツール「CPAT-GUI」を、Python スクリプトを用いて自動操作し、大量のシミュレーションケースを連続実行するためのものです。

**「何を」「どうする」システムか：**
*   **何を：** CPAT-GUI という Windows 用ソフトウェアと、その解析条件（Excel ファイル）を
*   **どうする：** Python スクリプトがマウスやキーボードを自動操作（マクロ実行）することで、人間が手作業で行う「条件変更 → 解析実行 → 結果保存」のサイクルを全自動で数百回繰り返すシステムです。

---

## 2. 必要な環境と準備

本システムを構築・実行するためには、以下の環境を準備する必要があります。

### 2.1. 必要なソフトウェア

| ソフトウェア名 | 用途 | 備考 |
| :--- | :--- | :--- |
| **Windows OS** | CPAT-GUI および自動化スクリプトの実行環境 | CPAT-GUI が Windows 専用のため必須です。 |
| **CPAT-GUI (R06 Ver.1.0)** | 電力系統の過渡安定度解析・潮流計算 | 事前にライセンス申請とインストールが必要です。 |
| **Python 3.x** | 自動化スクリプトの実行 | 実行に必要なライブラリ（後述）をインストールします。 |
| **Microsoft Excel** | 解析条件の編集と保存 | スクリプトから Excel を自動操作するために必要です。 |

### 2.2. Python ライブラリのインストール

コマンドプロンプトまたは PowerShell を開き、以下のコマンドを実行して必要なライブラリをインストールします。

```bash
pip install pyautogui pygetwindow pynput pyperclip openpyxl pandas numpy pywin32
```

## 3. フォルダ構成とファイルの役割

システム（リポジトリ）の主要なフォルダ構成と、それぞれの役割は以下の通りです。

*   **`CPATPub/`**: CPAT-GUI 本体の実行環境です。
    *   `CPAT.exe`: CPAT-GUI の起動ファイルです。
    *   `CPAT/`: 計算エンジン（`dynax.exe` など）が格納されています。
    *   `Manual/`: CPAT-GUI の操作マニュアル（PDF）が格納されています。
*   **`CPATPub/main/`**: 自動解析を実行するためのメイン作業フォルダです。
    *   `condition/`: 事故条件などを定義した Excel ファイルが格納されています。
    *   `mdl/`: 解析に使用するベースとなる系統モデルデータ（`.pop` ファイル）が格納されています。
    *   **`python/`**: **自動化の要となる Python スクリプト群**が格納されています。

### 3.1. 主要な Python スクリプトの役割

`CPATPub/main/python/` フォルダ内の主要なスクリプトは以下の役割を持ちます。

| ファイル名 | 役割 |
| :--- | :--- |
| **`main_v4.py`** | **自動解析のメイン実行スクリプト**です。このファイルを実行することで自動化が開始されます。 |
| **`config.ini`** | **システムの設定ファイル**です。フォルダパスや解析条件をここで一括管理します。 |
| `gui_actions.py` | CPAT-GUI の画面操作（画像認識・ショートカットキー）を安定して行うためのモジュールです。 |
| `MakeFile.py` | Excel の条件ファイルから、CPAT が読み込める形式のファイル（`.pop` や `.pnsy`）を自動生成します。 |

## 4. ユーザーが準備すべきデータ

システムを動かす前に、以下のデータを準備・確認する必要があります。

### 4.1. ベース系統モデルファイル（.pop）の準備

`config.ini` の `source` に指定されているベース系統モデルファイル名と、実際に `mdl/` フォルダに入っているファイル名が一致している必要があります。

**対応方法：**
`CPATPub/main/python/config.ini` をテキストエディタで開き、`source` の行を実際のファイル名に合わせて書き換えてください。

```ini
# 変更前（例）
source = ../mdl/EAST10peak_AllThermal_AllDemand_auto_res_SPM_R06.pop

# 変更後（実際のファイル名に合わせる）
source = ../mdl/275-500kVloop_EAST10peak_10SG_3RES_1SC.pop
```

> **【参考】ベース系統モデルの作成・変更方法**
> 新しいモデルを作る場合は、ゼロから作成するのではなく、**既存の `.pop` ファイルを CPAT-GUI で開いて改造（パラメータ変更）し、別名保存する**方法が最も簡単です。保存後、`config.ini` の `source` をその新しいファイル名に変更してください。詳細な操作方法は `CPATPub/Manual/00本体/Help.pdf` を参照してください。

### 4.2. 結果保存用フォルダの作成

解析結果を一時的に保存するためのフォルダが必要です。

**対応方法：**
`CPATPub/main/` フォルダの中に、手動で **`Temp`** という名前の空フォルダを作成してください。

### 4.3. GUI 操作用の画像ファイル（任意・推奨）

GUI 操作をより安定させるため、CPAT-GUI のボタン画像を画像認識に使用できます。

**対応方法：**
`CPATPub/main/python/gui_images/` フォルダ内に、以下のスクリーンショット（PNG 形式）を保存してください。画像がない場合はキーボードショートカットで動作します。
*   `btn_run.png` : 「シミュレーション実行」ボタン
*   `btn_save_csv.png` : 「CSV 保存」ボタン
*   `btn_no.png` : 「保存しますか？」ダイアログの「いいえ」ボタン

## 5. システム実行手順

準備が整ったら、以下の手順で自動解析を実行します。

### 手順 1：解析条件の設定

`CPATPub/main/python/config.ini` をテキストエディタで開き、`[analysis]` セクションの解析条件を設定します。

#### 「k1 パラメータ」とは何か？
`k1` は、**事故の規模や深刻度を決める変動パラメータ**です。設定した `contingency_case`（事故種別）によって、`k1` が意味する物理量が異なります。

| 事故種別 (`contingency_case`) | `k1` の意味 | 単位 | 備考 |
| :--- | :--- | :--- | :--- |
| **1 (負荷増加)** | **負荷増加量 (ΔP)** | MW | 指定したバスの負荷をどれだけ急増させるか。例：250MW〜1000MW まで 250MW 刻みで解析。 |
| **2 (短絡)** | **短絡継続時間** | サイクル | 事故が発生してから遮断器が動作するまでの時間。例：1 サイクル〜15 サイクルまで 1 サイクル刻みで解析。 |

```ini
[analysis]
# 事故種別 (1: 負荷増加, 2: 短絡)
contingency_case = 2
# 事故箇所数
target_of_number = 1

# --- 負荷増加 (case=1) の場合の k1 範囲 ---
k1_start_L = 250
k1_end_L   = 1001
delta_k1_L = 250

# --- 短絡 (case=2) の場合の k1 範囲 ---
# ※ 内部で ÷100 されるため、サイクル数×100 で指定してください
#    例: 1〜15サイクル, 1サイクル刻み → 100, 1600, 100
k1_start_GOC = 100
k1_end_GOC   = 1600
delta_k1_GOC = 100
```

### 手順 2：自動解析の実行

1.  コマンドプロンプトまたは PowerShell を開き、Python スクリプトがあるフォルダに移動します。
    ```bash
    cd (リポジトリのパス)\CPATPub\main\python
    ```
2.  メインスクリプトを実行します。
    ```bash
    python main_v4.py
    ```
3.  **実行中の注意：** スクリプトが起動すると、マウスとキーボードが自動的に動き出し、CPAT-GUI や Excel が勝手に開閉されます。**実行中は絶対にマウスやキーボードに触れないでください。** 操作がずれてエラーの原因になります。

## 6. 過去の課題と改善点（引き継ぎ事項）

以前のシステムにはいくつかの課題がありましたが、現在は以下の通り改善されています。

1.  **絶対パスの排除（相対パス化）：**
    以前は `C:\Users\...` という特定の PC に依存した絶対パスがコード内に直書きされていましたが、現在はすべて**相対パス**に変更されています。これにより、どの PC のどのフォルダにリポジトリを配置しても、パスの書き換えなしで動作するようになりました。
2.  **設定ファイル（config.ini）の導入：**
    解析条件やフォルダパスを Python コードから分離し、`config.ini` で一括管理するようにしました。これにより、Python のコードを一切編集することなく、条件変更が可能になりました。
3.  **GUI 操作の堅牢化：**
    以前は画面の絶対座標（X, Y）をクリックする方式だったため、画面解像度が変わると動かなくなる問題がありました。現在は `gui_actions.py` を導入し、**「画像認識によるクリック」と「キーボードショートカット」を組み合わせた堅牢な操作方式**に改善されています。
4.  **k1 パラメータのバグ修正：**
    短絡ケース（case=2）において、`k1` の値が正しく生成されない問題がありました。現在は `config.ini` で `100` 単位で指定することで、正しく `1〜15` サイクルが生成されるように修正されています。
