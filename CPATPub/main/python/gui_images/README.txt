================================================================
gui_images フォルダ  ―  画像認識用スクリーンショット置き場
================================================================

このフォルダに CPAT-GUI のボタン画像を配置することで、
座標クリックではなく「画像認識」による GUI 操作が有効になります。

【必要な画像ファイル一覧】

  btn_run.png      ← CPAT の「シミュレーション実行」ボタン
  btn_save_csv.png ← CPAT の「CSV 保存」ボタン
  btn_no.png       ← 「保存しますか？」ダイアログの「いいえ」ボタン

【スクリーンショットの撮り方】

  1. CPAT を起動して、対象のボタンを画面に表示する
  2. Win + Shift + S（Snipping Tool）でボタン部分だけを切り抜く
  3. 上記のファイル名でこのフォルダに保存する（PNG 形式推奨）

【画像がない場合の動作】

  画像ファイルが存在しない場合は、キーボードショートカットによる
  フォールバック操作が自動的に使用されます。
  そのため、画像がなくても動作しますが、より確実な操作のために
  画像を用意することを推奨します。
